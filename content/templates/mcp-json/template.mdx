## Connect and check the server

Save `.mcp.json` in the repository root. Open Claude Code from the project, approve the server if prompted, then run `/mcp` and sign in to Sniptide. Check that the server shows as connected. Commit the file if everyone on the project should see the entry.

You can create the same project configuration from the terminal and inspect it before opening Claude Code.

```bash title="Terminal"
claude mcp add --scope project --transport http sniptide https://app.sniptide.com/api/mcp
claude mcp list
```

Use `--scope local` for a connection just for you in this project, or `--scope user` for your own connections across projects. [Claude Code MCP configuration](https://code.claude.com/docs/en/mcp)

## Variant for a remote server with a token

Add the `github` entry under `mcpServers` if you need GitHub tools. Use a token scoped to the repositories and read permissions you need. Supply `GITHUB_TOKEN` to the environment that launches Claude Code. A value stored in a project `.env` file is only available here if your launcher loads it.

```json title=".mcp.json"
{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/readonly",
      "headers": {
        "Authorization": "Bearer ${GITHUB_TOKEN}"
      }
    }
  }
}
```

If the connection fails, check the token's scope and whether the variable is present in the launching shell. Keep the token out of the JSON and command history. [GitHub MCP setup for Claude](https://github.com/github/github-mcp-server/blob/main/docs/installation-guides/install-claude.md)

## Variant for a local stdio server

A stdio entry launches a process on your machine. This example requires Node.js and npm. Set `MCP_DOCS_DIR` to an absolute path to an existing directory you want the server to access. Pin a reviewed version of the package in a shared config before approving it.

```json title=".mcp.json"
{
  "mcpServers": {
    "filesystem": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "${MCP_DOCS_DIR}"]
    }
  }
}
```

This server can read and write files. Check the allowed directories and the client's approval settings before using it. For a quick test, ask it to list the files in your docs directory. [Filesystem MCP server](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem)
