## Publish a short index

Replace Acme and every sample URL with your product and public documentation. Put `llms.txt` at the root of the site and serve it as UTF-8 text. For Next.js, save a static file as `public/llms.txt`.

Check the deployed URL and each link in a signed-out browser, or fetch the file from a terminal. Expect the Markdown title and link list.

```bash title="Terminal"
curl -fsS https://example.com/llms.txt
```

`llms.txt` is a proposal for a curated Markdown index. Tools can use it when they fetch it. Use the index alongside your sitemap and keep crawler preferences in `robots.txt`. [llms.txt proposal](https://llmstxt.org/)

## What each part does

| Part | What to include |
| --- | --- |
| H1 | Your product or documentation name. |
| Blockquote | A short summary of what the product does and who uses it. |
| Details | Facts that apply across pages, such as the units an API uses. |
| H2 sections | A small set of links grouped by task. Describe what each link answers. |
| Optional | Secondary links, such as release notes, that can be skipped when context is limited. |

Use stable public URLs. Link to a Markdown version if you publish one. Keep the normal page URL when it is the available source. Adding `.md` to a URL requires your site to serve that route.

## Generate it from a docs catalog

If your docs source already provides titles and public URLs, generate the link list from that catalog at build time. This route shows the response format using two sample entries. Use either this route or the static file above for `/llms.txt`.

```ts title="app/llms.txt/route.ts"
const docs = [
  { title: "Quickstart", url: "https://example.com/docs/quickstart", detail: "Send an invoice" },
  { title: "Webhooks", url: "https://example.com/docs/webhooks", detail: "Verify event signatures" },
]

export const dynamic = "force-static"

export function GET() {
  const links = docs.map(({ title, url, detail }) => `- [${title}](${url}): ${detail}`).join("\n")
  const body = `# Acme\n\n> Acme is an invoicing API.\n\n## Docs\n\n${links}\n`

  return new Response(body, {
    headers: { "Content-Type": "text/plain; charset=utf-8" },
  })
}
```

Keep the index short enough to scan. If you also offer a full-text export such as `llms-full.txt`, link to it as optional material and check that it includes only public content.
