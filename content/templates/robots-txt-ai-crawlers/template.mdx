## Publish and check the policy

Serve the file as plain text at `https://your-domain/robots.txt`. Replace the sample sitemap URL and choose the public paths each crawler may fetch. Use a separate file on each host that needs a policy, such as your docs subdomain.

Open the live URL after deployment. Check that it returns HTTP 200 and shows the intended rules. Try a public docs URL and a restricted path in your crawler's testing tool. The rule `/app/` matches URLs starting with `/app/`, so test bare `/app` separately if your site serves it.

## Choose which uses to allow

| Token | What the sample policy requests |
| --- | --- |
| `OAI-SearchBot`, `Claude-SearchBot`, `PerplexityBot` | Allow crawling of public pages for AI search. |
| `GPTBot`, `ClaudeBot` | Decline crawling for model training. |
| `CCBot` | Keep pages out of new Common Crawl crawls. |
| `Google-Extended` | Decline the Gemini training and grounding uses Google describes. This token is separate from Google Search inclusion. |
| `Applebot-Extended` | Decline Apple foundation model training on pages Applebot crawls. |

Allowing a search crawler makes a page available to that crawler. Each provider decides what to index or show. Check the provider policies as part of each review. [OpenAI](https://developers.openai.com/api/docs/bots) · [Anthropic](https://privacy.anthropic.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler) · [Perplexity](https://docs.perplexity.ai/docs/resources/perplexity-crawlers) · [Common Crawl](https://commoncrawl.org/ccbot) · [Google](https://developers.google.com/crawling/docs/crawlers-fetchers/google-common-crawlers) · [Apple](https://support.apple.com/en-us/119829)

## Keep private pages behind access control

Enforce authentication or network restrictions on private resources. Some fetches initiated by a person, such as `ChatGPT-User` and `Perplexity-User` requests, may bypass crawler rules. Changes also take time to reach cached copies of the policy. [Robots Exclusion Protocol](https://www.rfc-editor.org/rfc/rfc9309.html)

## Block the named AI search crawlers too

Move the three search tokens into the `Disallow: /` group. Keep the wildcard group for general search and other crawlers. Named groups use their own path rules, so repeat any shared exclusions in each group that permits some crawling.

To give tools a short map of your public documentation, publish an [llms.txt](/templates/llms-txt).
