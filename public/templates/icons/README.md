# Template card icons

Templates for a tool without artwork in `public/logos` show one of these icons on their card and
share image. They come from [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme)
by Material Extensions, under the MIT license, the same set the app uses for language icons. Each
file is the icon's original body from `@iconify-json/material-icon-theme` 1.2.75, wrapped in an
`svg` element with an accessible name and explicit `width` and `height` so every browser and the share image renderer
can size it.
