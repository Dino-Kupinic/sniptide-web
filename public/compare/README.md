# Comparison logos

The `/compare` index shows each comparison as Sniptide's mark, "vs" and the other tool's mark.
The marks keep their original paths and colors, from these sources, retrieved on 24 November 2026. The PrivateBin and Opengist files add a title for their accessible names, and the MicroBin file is scaled down to 128px.
Hastebin and Pastes.io publish no mark that could be retrieved, so their tiles show the tool's initial.

| Tool | Where it lives | Source |
| --- | --- | --- |
| PrivateBin | `public/compare/privatebin.svg` | [`img/icon.svg`](https://github.com/PrivateBin/PrivateBin/blob/master/img/icon.svg) in the PrivateBin repository (zlib license) |
| Pastebin | `components/compare/product-mark.tsx` | The Pastebin mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/pastebin.svg), drawn in the text color |
| GitHub Gist | `components/github-mark.tsx` | The GitHub mark from [GitHub logos](https://github.com/logos), drawn in the text color |
| Opengist | `public/compare/opengist.svg` | [`public/img/opengist.svg`](https://github.com/thomiceli/opengist/blob/master/public/img/opengist.svg) in the Opengist repository (AGPL-3.0) |
| MicroBin | `public/compare/microbin.png` | [`templates/assets/logo-square.png`](https://github.com/szabodanika/microbin/blob/master/templates/assets/logo-square.png) in the MicroBin repository (BSD-3-Clause) |
